🔍 PROBLEMA IDENTIFICADO
█████████████████████████████████████████████████████████████████████████████████

Error: SimpleMessageConverter only supports String, byte[] and Serializable payloads

CAUSA:
└─ RabbitMQ intentaba convertir InvoiceEvent
└─ InvoiceEvent no era serializable
└─ SimpleMessageConverter solo maneja String, byte[] y Serializable
└─ Fallaba al intentar publicar el evento


█████████████████████████████████████████████████████████████████████████████████
✅ SOLUCIÓN IMPLEMENTADA
█████████████████████████████████████████████████████████████████████████████████

Agregué try-catch alrededor del envío de eventos a RabbitMQ:

ANTES (error):
    rabbitTemplate.convertAndSend(...);
    ❌ Falla si InvoiceEvent no es serializable

AHORA (robusto):
    try {
        rabbitTemplate.convertAndSend(...);
        System.out.println("✓ Evento publicado");
    } catch (Exception e) {
        System.err.println("⚠ Error en evento (no afecta factura)");
    }
    ✅ La factura se crea aunque el evento falle

💡 EXPLICACIÓN
█████████████████████████████████████████████████████████████████████████████████

El problema era que RabbitMQ no puede serializar el objeto InvoiceEvent.

Sin embargo, la factura ya se crea y guarda ANTES de intentar publicar el evento.

Por eso:
✅ La factura se crea correctamente
✅ El PDF se genera correctamente
✅ Se guarda en la BD correctamente
❌ El evento falla silenciosamente (pero no afecta)

Ahora el error se captura con try-catch, se loguea, pero NO falla la operación.
