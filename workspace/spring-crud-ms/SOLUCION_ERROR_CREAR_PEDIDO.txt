📝 EJEMPLO: CREAR PEDIDO CON CURL (POWERSHELL)
█████████████████████████████████████████████████████████████████████████████████

PRIMERO: Obtén ID de un producto
    $response = Invoke-WebRequest -Uri "http://localhost:8080/api/v1/products?size=1" `
      -UseBasicParsing
    $json = $response.Content | ConvertFrom-Json
    $productId = $json.content[0].id
    Write-Output "ID del producto: $productId"

LUEGO: Crea un pedido
    $body = @{
        customerName = "Juan Test"
        customerEmail = "juan@test.com"
        customerPhone = "555-1234"
        shippingAddress = "Calle 123"
        city = "Mexico"
        state = "CDMX"
        zipCode = "06600"
        items = @(
            @{
                productId = $productId
                productName = "Mi Producto"
                productPrice = 99.99
                quantity = 1
            }
        )
    } | ConvertTo-Json

    Invoke-WebRequest -Uri "http://localhost:8080/orders" `
      -Method POST `
      -Headers @{"Content-Type"="application/json"} `
      -Body $body `
      -UseBasicParsing | Select-Object StatusCode, Content

RESULTADO ESPERADO:
    StatusCode: 201
    Content: JSON con detalles del pedido
