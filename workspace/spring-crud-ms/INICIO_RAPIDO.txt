PASO 1️⃣  - COMPILA (Primera vez - ~60 segundos)
════════════════════════════════════════════════════════════════════════

Abre PowerShell y ejecuta:

  cd "C:\Nueva carpeta\agentic-sdlc-sdd-arch-opencode-main\workspace\spring-crud-ms"
  mvn clean package -q

Espera a que termine. Verás:
  ✅ BUILD SUCCESS


PASO 2️⃣  - INICIA LA APLICACIÓN
════════════════════════════════════════════════════════════════════════

Opción A (Recomendado - se abre el navegador automáticamente):

  .\INICIA_APLICACION.ps1

O manualmente:

  java -jar target/spring-crud-ms-1.0.0-SNAPSHOT.jar

Espera a ver:

  ✅ Tomcat started on port(s): 8080 (http)
  ✅ SpringCrudMsApplication started in X.XXX seconds


PASO 3️⃣  - ABRE EN EL NAVEGADOR
════════════════════════════════════════════════════════════════════════

http://localhost:8080

¡Ya estás listo para hacer pruebas! 🎉

¿QUÉ PUEDES HACER AHORA?
════════════════════════════════════════════════════════════════════════

✨ En la Interfaz Gráfica:

  1. ➕ CREAR PRODUCTO
     • Rellena el formulario
     • Haz clic en "Guardar"
     • Aparece en la tabla

  2. 📋 VER LISTA
     • Se actualiza cada 5 segundos
     • Muestra todos tus productos

  3. ✏️ EDITAR PRODUCTO
     • Haz clic en "Editar"
     • Modifica los datos
     • Haz clic en "Guardar"

  4. 🗑️ ELIMINAR PRODUCTO
     • Haz clic en "Eliminar"
     • Confirma la acción

  5. 👁️ VER DETALLES
     • Haz clic en "Ver"
     • Se muestra toda la información
