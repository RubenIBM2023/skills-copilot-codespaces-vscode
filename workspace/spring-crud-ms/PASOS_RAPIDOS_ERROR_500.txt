🔍 QUÉ ERA EL PROBLEMA
════════════════════════════════════════════════════════════════════════

Error 500 = El servidor recibe la solicitud pero falla internamente

CAUSA: Incompatibilidad de tipos
  • JavaScript envía: 99.99 (número decimal)
  • Spring esperaba: BigDecimal (tipo especial)
  • Resultado: CRASH al intentar convertir

SOLUCIÓN: Cambié el DTO para aceptar Double en lugar de BigDecimal
  • Ahora JavaScript puede enviar números normales
  • Spring los convierte automáticamente a BigDecimal internamente
  • ¡Sin más errores 500!
