🔴 EJEMPLOS DE ERRORES Y SOLUCIONES
█████████████████████████████████████████████████████████████████████████████████

SI VES EN LOGS:
   "La orden debe tener al menos 1 item"

SOLUCIÓN:
   └─ El HTML no está enviando los items
   └─ Ve a F12 → Network → Request body
   └─ Verifica que "items" no esté vacío


─────────────────────────────────────────────────────────────────────────────

SI VES EN LOGS:
   "NullPointerException"

SOLUCIÓN:
   └─ Busca qué línea causa el error
   └─ Generalmente es productService.findById()
   └─ Verifca que el ID del producto sea correcto


─────────────────────────────────────────────────────────────────────────────

SI VES EN LOGS:
   "Column X cannot be null"

SOLUCIÓN:
   └─ Algún campo requerido está vacío
   └─ Llena TODOS los campos en el formulario
   └─ No dejes nada en blanco


─────────────────────────────────────────────────────────────────────────────

SI DICE EN F12:
   "Failed to load resource: the server responded with a status of 500"
   
PERO EN LOGS NO VES "=== ERROR EN ENDPOINT ===" :

SOLUCIÓN:
   └─ La aplicación se crasheó
   └─ Reinicia: Ctrl+C en PowerShell, luego java -jar...
   └─ Mira los logs al iniciar

🧪 ALTERNATIVA: PRUEBA CON CURL
█████████████████████████████████████████████████████████████████████████████████

Esta es la MEJOR forma porque ves el error exacto:

PASO 1: Get product ID

    $response = Invoke-WebRequest "http://localhost:8080/api/v1/products?size=1" `
      -Headers @{"Content-Type"="application/json"} -UseBasicParsing
    
    $json = $response.Content | ConvertFrom-Json
    $product = $json.content[0]
    
    Write-Host "ID: $($product.id)"
    Write-Host "Name: $($product.name)"
    Write-Host "Price: $($product.price)"


PASO 2: Create order with curl

    $productId = [string]$product.id  # Copia el ID que viste arriba
    
    $body = @{
        customerName = "John Test"
        customerEmail = "test@test.com"
        customerPhone = "5551234567"
        shippingAddress = "123 Main"
        city = "TestCity"
        state = "TS"
        zipCode = "12345"
        items = @(
            @{
                productId = $productId
                productName = $product.name
                productPrice = $product.price
                quantity = 1
            }
        )
    } | ConvertTo-Json

    Write-Host "Body:" -ForegroundColor Yellow
    Write-Host $body -ForegroundColor Cyan
    
    $response = Invoke-WebRequest "http://localhost:8080/orders" `
      -Method POST `
      -Headers @{"Content-Type"="application/json"} `
      -Body $body `
      -UseBasicParsing

    Write-Host "StatusCode:" $response.StatusCode -ForegroundColor Green
    Write-Host "Response:" -ForegroundColor Green
    $response.Content


RESULTADO ESPERADO SI FUNCIONA:
    
    StatusCode: 201
    Response: {"id":1,"orderNumber":"ORD-123...","status":"PENDING",...}


RESULTADO SI FALLA:

    StatusCode: 500
    Response: {"status":500,"error":"NullPointerException",...}
             O
             {"status":500,"error":"DataIntegrityViolationException",...}
