🔍 EL PROBLEMA: Error de configuración MongoClientSettings
════════════════════════════════════════════════════════════════════════

Error:
  "Parameter 2 of method syncClientServerWrapper required a bean of 
   type 'com.mongodb.MongoClientSettings' that could not be found"

CAUSA:
  • Spring Boot 3.x + Flapdoodle manejan la configuración automáticamente
  • Creé una configuración manual que conflictúa con la automática
  • El conflicto causaba que faltara MongoClientSettings

SOLUCIÓN:
  • Simplificacé la configuración
  • Ahora dejo que Spring Boot + Flapdoodle manejen todo automáticamente
  • MongoConfig solo habilita @EnableMongoAuditing
  • application.properties tiene la configuración correcta


✅ CAMBIOS REALIZADOS
════════════════════════════════════════════════════════════════════════

1. Eliminé MongodbConfiguration.java
   • No es necesaria
   • Spring Boot 3.x lo maneja automáticamente

2. Mantuve MongoConfig.java
   • @EnableMongoAuditing
   • Para createdAt/updatedAt automático

3. Simplifiqué application.properties
   • spring.data.mongodb.database=products_db
   • de.flapdoodle.mongodb.embedded.version=7.0.2
   • Logging: INFO (no DEBUG para menos ruido)
