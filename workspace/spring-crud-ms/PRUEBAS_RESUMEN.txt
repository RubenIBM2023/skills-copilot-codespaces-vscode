PRUEBA 1: Flujo Completo CRUD
─────────────────────────────
1. Crear: Laptop Dell XPS 13 | $1299.99 | Stock: 5
2. Leer: Verificar que aparece en la lista
3. Actualizar: Cambiar precio a $1199.99
4. Patch: Cambiar stock a 10
5. Eliminar: Remover el producto

✅ Esperado: Todas las operaciones exitosas

PRUEBA 2: Validaciones de Entrada
──────────────────────────────────
1. Intentar crear sin nombre → Debe retornar 400
2. Intentar crear con precio negativo → Debe retornar 400
3. Intentar crear con stock negativo → Debe retornar 400

✅ Esperado: Todas retornan 400 Bad Request

PRUEBA 3: Manejo de Errores
───────────────────────────
1. Obtener producto con ID inexistente → Debe retornar 404
2. Actualizar producto ID inexistente → Debe retornar 404
3. Eliminar producto ID inexistente → Debe retornar 404

✅ Esperado: Todas retornan 404 Not Found

PRUEBA 4: Paginación
───────────────────
1. Crear 15 productos
2. Obtener con ?page=0&size=10 → Retorna 10
3. Obtener con ?page=1&size=10 → Retorna 5

✅ Esperado: Paginación funciona correctamente

📊 ENDPOINTS API
════════════════════════════════════════════════════════════════════════

POST   /api/v1/products
  → Crear producto
  → Status: 201 Created
  → Body: ProductRequestDTO

GET    /api/v1/products
  → Listar todos (con paginación)
  → Status: 200 OK
  → Parámetros: ?page=0&size=10

GET    /api/v1/products/{id}
  → Obtener por ID
  → Status: 200 OK o 404 Not Found

PUT    /api/v1/products/{id}
  → Actualizar completo
  → Status: 200 OK o 404 Not Found
  → Body: ProductRequestDTO

PATCH  /api/v1/products/{id}
  → Actualizar parcial
  → Status: 200 OK o 404 Not Found
  → Body: ProductPatchDTO (solo price, stock)

DELETE /api/v1/products/{id}
  → Eliminar
  → Status: 204 No Content o 404 Not Found
